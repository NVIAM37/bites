# NVIAM Maker — Official

NVIAM Maker is the official front-end application for the NVIAM Maker project. This repository contains a modern React + TypeScript UI scaffolded with Vite, using Tailwind CSS and shadcn-ui components.

## Key Technologies

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

## Getting Started

Prerequisites: Node.js (v18+ recommended) and a package manager (`npm`, `pnpm`, or `yarn`).

1. Clone the repository:

```bash
git clone <YOUR_GIT_URL>
cd <REPO_DIR>
```

2. Install dependencies:

```bash
npm install
# or
pnpm install
```

3. Start the development server:

```bash
npm run dev
```

4. Build for production:

```bash
npm run build
```

5. Preview the production build locally:

```bash
npm run preview
```

## Project Structure (high level)

- `src/` — Application source code (components, pages, styles)
- `public/` — Static assets
- `package.json` — Scripts and dependencies

## Notes on Sensitive Files

This repository previously contained an environment file `.env`. That file has been removed from the repository to avoid committing secrets. Keep any required environment values in a local, untracked `.env` file or in your CI/CD secrets store.
